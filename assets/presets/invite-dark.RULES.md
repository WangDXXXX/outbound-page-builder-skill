# invite-dark 设计系统规则

配 `invite-dark.css`。邀请函（invite）体裁的兜底设计系统——没有真实四件套输入、也没有前作可继承时用这一套。五节结构 + 可选第六节，与 `references/design-inject.md` 的令牌层是同一套。

## 1. 色板（不新增色相）

只有一个强调色相（暖锈色 ember-rust，`--accent`）。这套关系**没有独立的第二强调色**——`--accent-2` 直接等于 `--accent`（`var(--accent)`），不新画一个"高潮色"。亮色反转段是这套关系的识别特征，不是可选项。

| 令牌 | 值 | 角色 |
|---|---|---|
| `--bg` | `#0b0b0b` | 画布 |
| `--bg-2` | `#272a2a` | 卡面 |
| `--bg-sunken` | `#050505` | 凹陷（比画布更深一级） |
| `--fg` | `#ffffff` | 主文字 |
| `--fg-2` | `#edebe7` | 次文字（暖白，不是纯白） |
| `--fg-3` | `#484848` | 弱文字 / 注脚 |
| `--hair` | `rgba(255,255,255,.12)` | 发丝线 1px |
| `--accent` | `#cc6437` | 唯一强调色，配给制 |
| `--accent-2` | `var(--accent)` | 等同 `--accent`，见第 1 节 |
| `--invert-bg` | `#edebe7` | 亮色反转段背景（骨白 bone） |
| `--invert-fg` | `#050505` | 亮色反转段文字 |

**✅ `hook-grid`（亮色反转段组件）里的高亮项用 `--accent`。❌ 反转段的说明文字用 `--fg-2`/`--fg-3`——那两个令牌是为暗底调的浅色，糊在 `--invert-bg` 这种亮底上基本不可读；反转段内的弱化文字改用中性 `rgba(0,0,0,α)` 遮罩（`hook-grid` 组件的 `.pour .en`/`.pour .n` 已经这样写），不要复用暗色区的文字令牌。**

## 2. 字体层级

- 中文正文：`--font-cn`（PingFang SC / Hiragino Sans GB / Microsoft YaHei）。**中文是主角，字号不得小于同屏英文/数字。**
- 数字与英文缩写：`--font-mono`，只用于须知编号、议程时间这类"读数"场景。
- 字号层级由组件 CSS 内建，本预设不单独覆盖。

## 3. 形状与体积

- 圆角三级：`--radius-s 1px`（近似直角，用于须知列表的分隔线容器）／`--radius-m 4px`（议题卡片圆角，克制）／`--radius-l 10px`（二维码闭环等大容器）。这套关系的圆角克制、接近直角，不是战报向那种大圆角柔和风——**换设计系统时不要把 `recap-dark` 的圆角数值直接搬过来，两套形状语言是不同的**。
- 间距三级：`--pad 20px`／`--gap 56px`／`--maxw 1240px`，与 `recap-dark` 相同（间距节奏是跨设计系统共享的结构令牌，不属于"品牌可换"的部分）。

## 4. 品牌固定件

- Logo、活动贴纸等品牌资产一律使用官方原始文件，**不自行抠图、不改色、不加投影**。自带白色模切边的贴纸类资产，边框就是设计的一部分，当贴纸直接贴。
- 页脚 logo：网页版 104px 宽，长图版收小到 74px（`footer-brand` 组件按 `mode` 自动切换）。
- 品牌色（`--accent`）只用于强调（须知编号、议题卡装饰线、二维码提示文案），不用于大面积铺底。

## 5. 禁令

- ❌ 不新增本文件之外的色相（第 1 节已说明）。
- ❌ 不在 `--font-cn` 里塞入不含 CJK 字形的西文专属字体——本预设的字体栈刻意不引入任何品牌专属西文字体作为中文主栈，理由与 `recap-dark` 相同：邀请函正文以中文为主，专属西文字体对中文没有字形覆盖，会静默回退到系统默认字体。
- ❌ 不给亮色反转段（`hook-grid`）加阴影让它"浮起来"——Ciridae 一类暖锈色系统的真实踩坑：反转段要用纯色块表达，不靠投影制造层次。
- ❌ 不把反转段内的弱化文字复用暗色区的 `--fg-2`/`--fg-3`（第 1 节已说明，这是本预设与 `recap-dark` 唯一的令牌用法差异，容易在复制粘贴组件代码时漏改）。

## 6.〔可选〕高潮时刻

本预设没有独立的 `--accent-2`，所以没有传统意义上的"第二档强调色"可用。真正需要在全页里做一次视觉破戒时，改用**亮色反转段本身**作为高潮时刻的容器——`hook-grid` 整块从暗底切到 `--invert-bg`，这个"底色反转"动作本身就是这套关系里唯一允许的一次破例，不需要再叠加额外颜色。
