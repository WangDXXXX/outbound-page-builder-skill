# recap-dark 设计系统规则

配 `recap-dark.css`。战报（recap）体裁的兜底设计系统——没有真实四件套输入、也没有前作可继承时用这一套。五节结构 + 可选第六节，沿用本项目所有设计系统规则文档统一的骨架，与 `references/design-inject.md` 的令牌层是同一套。

## 1. 色板（不新增色相）

只有一个强调色相（信号紫，`--accent` / `--accent-2` 两级）。除 `--accent` 与 `--accent-2` 外，画面里不允许出现第三个彩色色相——氛围层（`atm-layer`）、图表配色（`donut`／`compare-bars`）全部只从 `--accent` `--accent-2` `--fg-2` `--fg-3` 四个令牌里循环取色，不新画一个颜色。

| 令牌 | 值 | 角色 |
|---|---|---|
| `--bg` | `#090909` | 画布 |
| `--bg-2` | `#474747` | 卡面 |
| `--bg-sunken` | `#050505` | 凹陷（比画布更深一级） |
| `--fg` | `#f7f9fa` | 主文字 |
| `--fg-2` | `#f0f0f0` | 次文字 |
| `--fg-3` | `#828384` | 弱文字 / 注脚 |
| `--hair` | `rgba(255,255,255,.12)` | 发丝线 1px |
| `--accent` | `#af50ff` | 唯一强调色，配给制 |
| `--accent-2` | `#e1bdff` | 仅「高潮时刻」可用，见第 6 节 |
| `--invert-bg` | `#f0f0f0` | 亮色反转段背景 |
| `--invert-fg` | `#090909` | 亮色反转段文字 |

**✅ 数字用 `--accent`、图例第二档用 `--accent-2`。❌ 图表第三档另起一个新色相（比如加一个绿色）——第三档起必须退到 `--fg-2`/`--fg-3` 这类中性色，`donut` 组件的调色板顺序就是这样写死的。**

## 2. 字体层级

- 中文正文：`--font-cn`（PingFang SC / Hiragino Sans GB / Microsoft YaHei）。**中文是主角，字号不得小于同屏英文/数字。**
- 数字与英文缩写：`--font-mono`，只用于 `stat-caption` 的数值、`donut`/`bar-h` 的百分比这类"读数"场景，不用于跑正文。
- 字号层级由组件 CSS 内建（`clamp()` 响应式），本预设不单独覆盖字号——换设计系统只换颜色与形状令牌，字号层级是组件契约的一部分，不是设计系统的输入项。

## 3. 形状与体积

- 圆角三级：`--radius-s 6px`（小元件，如徽标）／`--radius-m 10px`（卡片）／`--radius-l 16px`（按钮、大容器）。三级必须保持递增关系，不倒挂。
- 间距三级：`--pad 20px`（页面左右留白）／`--gap 56px`（区块之间的垂直间距）／`--maxw 1240px`（正文最大宽度）。
- 氛围层（`atm-layer`）用 `blur(70px)` 的模糊光斑制造纵深，不用直角色块——这是"暗底 + 光晕"这套关系的识别特征，换成硬边色块就不是这套语言了。

## 4. 品牌固定件

- Logo、活动贴纸等品牌资产一律使用官方原始文件，**不自行抠图、不改色、不加投影**。自带白色模切边的贴纸类资产，边框就是设计的一部分，当贴纸直接贴，不当成"没抠干净"去修。
- 页脚 logo：网页版 104px 宽，长图版收小到 74px（`footer-brand` 组件按 `mode` 自动切换，不需要手动传两套图）。
- 品牌色（`--accent`）只用于强调，不用于大面积铺底——铺底永远是 `--bg` / `--bg-2` / `--bg-sunken` 三级中性色。

## 5. 禁令

- ❌ 不新增本文件之外的色相（第 1 节已说明）。
- ❌ 不在 `--font-cn` 里塞入不含 CJK 字形的西文专属字体——本预设的字体栈刻意不引入任何品牌专属西文字体作为中文主栈，因为战报正文以中文为主，专属西文字体对中文没有字形覆盖，会静默回退到系统默认字体，读者会看到不一致的字重。品牌识别度要靠色板与形状语言，不靠强行塞进中文字体栈的西文字体。
- ❌ 不给品牌 logo 加阴影/发光让它"更突出"——氛围层已经提供纵深，logo 自己保持平面。
- ❌ 不把 `--accent` 用在大段正文文字颜色上——强调色是配给制，正文颜色只能是 `--fg` / `--fg-2` / `--fg-3`。

## 6.〔可选〕高潮时刻

`--accent-2`（`#e1bdff`）全页最多用在一处真正的"高光时刻"——例如 `compare-bars` 里对比线第二档、或某一屏唯一一次的强调点缀。不是每页都必须用到这一档；用不到就不用，不能为了"用满 19 个令牌"而找地方硬塞。
